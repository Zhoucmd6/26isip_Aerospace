## 1. 目的与边界

本文是从 E0/E1 代理升级到可追溯校准模型时的完整采集清单。它回答三件事：需要采什么数据、数据至少应包含什么、辨识结果写到哪里。本文是试验计划，不是已完成标定的证据。

控制器和 RL 不得读取本文中的完整功率曲面、真实最优点、辨识参数或未来风。真实数据只用于对象侧校准和留出验证，运行时仍通过 Plane / MeasurementAdapter 输出测量上下文。

三个仓库根目录受限源文件 `1_电芯测试报告f.pdf`、`PAW 40X13.1R_推力_18V-30V @MN1005-V2.0-KV100_测试数据2026-07-04_1.xlsx`、`物理建模指引_电机电池测试数据.md` 只能本地只读保存。不得通过移动、复制、改名或解除忽略规则将其加入 Git。Git 只保留允许共享的哈希、字段/单位、清洗规则、派生参数和验证摘要。

## 2. 配置入口与数据落点

| 内容 | 当前权威入口 | 用法 |
|---|---|---|
| X8 执行器、刚体、旋翼、气动、电池和诊断参数 | `models/px4_x8/+x8phys/config.m` | 当前全部是 MATLAB name/value 配置；校准值替换对应默认值前必须补来源和验证记录 |
| Plane 响应、联合功率、电池和场景门槛 | `models/plane/+plane/config.m` | 只用于统一 Plane 代理；与 X8PHYS 重复的物理量最终必须引用同一校准参数集 |
| X8PHYS 已有原始来源、清洗和拟合记录 | `models/px4_x8/data/X8PHYS_DATA.md` | 记录来源哈希、单位、拟合方法、适用范围和结论边界 |
| Plane 原始数据登记 | `models/plane/data/raw/` 与 `models/plane/data/README.md` | 原始文件只读；字段和单位未确认前不得进入配置 |
| 允许共享的清洗数据 | `models/plane/data/processed/` | 保存时间对齐、单位统一、异常点规则和来源哈希；目录按数据获准共享后创建 |
| 最终辨识参数与留出验证 | `models/px4_x8/data/calibration/`、`models/plane/data/calibration/` | 当前尚未建立参数装载器；新增前需确定 MAT/JSON schema、版本和回退规则 |

任何配置变更必须同时记录：参数名、单位、值、不确定度、原始数据哈希、清洗脚本版本、辨识脚本版本、适用工况、校准/留出数据 ID、审核人和日期。禁止只把一个数写进 `config.m` 而不留证据链。

## 3. 每份试验数据必须带的公共元数据

| 必采字段 | 最低要求 |
|---|---|
| 数据身份 | `dataset_id`、原始文件名、SHA-256、试验日期、操作者、试验地点 |
| 硬件身份 | 机架/电机/电调/桨/电池序列或批次、固件版本、接线和上下桨配对 |
| 仪器身份 | 传感器型号、量程、精度、校准日期、采样率、通道零偏 |
| 时间 | 单调时间戳、统一时基、各设备时钟偏移和对齐方法；不得只保留图像 |
| 单位和坐标 | 原始单位、SI 转换规则；机体系 FRD、惯性系 NED/NE、力矩正方向和风向定义 |
| 环境 | 温度、气压、湿度或空气密度；室内/室外、来流均匀性和地面效应距离 |
| 工况标签 | 稳态/阶跃/扫频/飞行段、目标值、实际值、重复编号、异常事件 |
| 质量控制 | 缺测、饱和、剪裁、异常点和人工剔除原因；保留未清洗原始值 |

## 4. 必须采集的数据与现有配置映射

### 4.1 整机几何、质量、重心和惯量

| 必采数据 | 建议工况/方法 | 现有配置位置 | 状态 |
|---|---|---|---|
| 起飞质量、各部件质量、载荷配置 | 分别称量空机、任务载荷和测试仪器，记录安装状态 | `x8phys.config.mass_kg`；`plane.config.mass_kg` | 两处当前均为 1.4 kg proxy，最终必须同源 |
| 重心三轴位置 | 悬挂/支点或称重法，至少对常用载荷配置复测 | 当前无字段 | 接入完整刚体前新增 `cg_body_m`，不得用 `arm_m` 代替 |
| 8 个旋翼中心三维坐标 | 以机体原点测量 FRD 坐标，记录上下桨高度差 | `arm_m`、`rotor_angle_rad` 只能表达简化平面对称布局 | 非对称布局需新增 `rotor_position_body_m[3x8]` |
| 桨直径、桨距、上下桨间距 | 游标/设计图；记录桨型号、安装方向和间距 | `rotor_radius_m`；上下桨间距当前无字段 | `rotor_radius_m` 已按 40 英寸直径设置；间距需新增字段 |
| 电机旋向和同轴配对 | 逐电机低速确认并录像/记录 | `rotor_direction`、`rotor_angle_rad` | 必须与 M2 配对和实物编号一致 |
| 三轴转动惯量和惯量积 | 双摆/扭摆或可信 CAD 质量模型，覆盖实际载荷 | `inertia_kgm2` | 当前为对角 proxy；实测后允许非零惯量积但必须对称正定 |

### 4.2 单电机/单桨静态推进

每条原始记录至少包含：时间、PWM/油门、电调输入电压和电流、RPM、推力、反扭矩、轴功率（若可测）、电机/电调/绕组温度、环境参数及稳态标志。

| 必采数据 | 工况覆盖 | 配置字段 |
|---|---|---|
| PWM 到 RPM、启动/停转和死区 | 覆盖允许电压、SOC、温度和完整 PWM 范围；上升/下降方向分别采集 | `pwm_min_us`、`pwm_max_us`、`omega_max_radps`、`motor_kv_rpm_per_V`、`pwm_edge_us` |
| RPM 到推力 | 每个电压档覆盖有效 RPM，低/中/高点重复；上下层电机分别检查 | `ct_N_per_rad2` |
| RPM 到反扭矩 | 与推力同步测量，固定力矩正方向 | `cm_Nm_per_rad2` |
| RPM 到电功率 | 同步电压、电流与 RPM，区分轴功率和电功率 | `prop_power_linear_W_per_rev_s`、`prop_power_cubic_W_per_rev_s3` |
| 电机与电调效率 | 有轴功率或扭矩/RPM 真值时辨识，并记录负载和温度 | `motor_electrical_efficiency`、`esc_efficiency`；当前只能表示常数 |

最低验证要求：按电压/硬件批次留出完整重复组，不得随机拆散同一条时间序列；报告拟合残差、最大误差、参数置信区间和超出测量范围时的外推标志。当前 2026-07-04 静推表只覆盖空速 0、约 225--1140 rpm，不能证明非零来流或动态响应。

### 4.3 同轴上下桨干扰

| 必采数据 | 工况覆盖 | 配置位置 |
|---|---|---|
| 单上桨、单下桨、双桨同时工作的推力/扭矩/功率 | 多个总推力、`eta=omega_upper/omega_lower` 网格、多个上下桨间距 | 当前无专用字段 |
| 上下桨各自 RPM、推力和扭矩 | 至少覆盖 M2 的 `eta` 允许范围及饱和边界 | 当前仅共享 `ct_N_per_rad2`、`cm_Nm_per_rad2` |
| 旋向、桨型和安装误差影响 | 正常配置及可重复的部件交换试验 | `rotor_direction` 仅记录旋向，不表达干扰 |

现有模型没有同轴干扰图。真实数据接入前应新增按总转速/`eta`/间距查询的推力、扭矩和功率修正，不得把全部干扰压进单一 `eta_power_gain_W` 后宣称已标定。

### 4.4 电机、电调和旋翼动态

| 必采数据 | 工况覆盖 | 配置字段 |
|---|---|---|
| PWM 阶跃到 RPM 的完整时间序列 | 多个初始/目标 PWM、电压、SOC、温度；分别测加速和减速 | `motor_tau_s` |
| PWM/RPM 变化率、延迟、过冲和滞回 | 阶跃、斜坡和扫频；采样率至少能分辨最快时间常数 | `omega_max_radps`；变化率/纯延迟/滞回当前无字段 |
| 电流限制、欠压降额和热降额 | 接近额定边界但保持台架安全，记录触发条件和恢复条件 | `max_power_W` 只能表达总功率上限；其余当前无字段 |

若一阶 `motor_tau_s` 不能通过留出阶跃，必须升级为上升/下降分离或状态相关模型，不应继续调一个时间常数掩盖结构误差。

### 4.5 非零来流旋翼气动

每条数据至少同步记录：三维来流、RPM、桨轴方向、推力、扭矩、轴/电功率、空气密度、上/下桨身份和稳态/动态标志。

| 必采数据 | 工况覆盖 | 配置字段 |
|---|---|---|
| 轴向来流下的推力/扭矩/功率 | 正负轴向速度、多个 RPM/推力点 | `rotor_axial_power_gain` 仅为标量 proxy |
| 前进比下的推力/扭矩/功率 | 覆盖任务空速和 RPM，计算 `J` 并保留原始量 | `rotor_advance_power_gain` 仅为标量 proxy |
| 侧向来流、倾斜盘面和动态入流 | 多个来流角、姿态和变化率 | 当前无字段 |
| 动态 `Ct(J)`、`Cq(J)`、`Cp(J)` | 单桨与同轴配置分别测量/CFD/BEMT 校核 | 当前无查表字段 |

最终应以有适用范围的查表/响应面替换两个 gain；在此之前所有非零空速结果保持 `proxy`。

### 4.6 机身气动与完整刚体响应

| 必采数据 | 工况覆盖 | 配置字段 |
|---|---|---|
| 三轴相对气流和三轴气动力 | 风洞、牵引/滑行或可辨识飞行段；覆盖任务速度、迎角和侧滑角 | `drag_area_m2`、`drag_coefficient`、`air_density_kgpm3` |
| 气动力矩、升力和侧力 | 多迎角/侧滑角及姿态组合 | 当前无力矩、升力或侧力系数字段 |
| 地速、空速、姿态、角速度、位置与控制输入 | 直线、转弯、加减速和扰动段，统一时基 | 用于联合验证 `mass_kg`、`inertia_kgm2` 和气动模型 |
| 空气密度或温压湿 | 每次试验同步记录 | `air_density_kgpm3` |

当前 `drag_area_m2 .* drag_coefficient` 是三轴二次阻力 proxy。若试验显示迎角/侧滑耦合明显，需扩展气动力/力矩模型而不是只改三个阻力系数。

### 4.7 电芯、电池包与供电链

| 必采数据 | 工况覆盖 | 配置字段 |
|---|---|---|
| 实际串并联、额定容量、单体/整包身份 | 逐包登记，确认均衡和保护板/接插件 | `battery_series`、`battery_parallel`、`cell_capacity_Ah`、`battery_capacity_Ah` |
| 静置 OCV-SOC | 充放电双向、充分静置、多个 SOC 点和温度 | `battery_ocv_soc`、`battery_ocv_cell_V` |
| 容量与库仑效率 | 多个倍率、温度和老化状态，完整充放电 | `cell_capacity_Ah`、`battery_capacity_Ah`；库仑效率当前无字段 |
| DCIR/脉冲响应 | 多 SOC、温度、倍率和脉冲长度 | `cell_resistance_ohm`、`battery_resistance_ohm` 只能表示常数 |
| 满充、空载下限、带载截止和恢复 | 按电芯/电调/任务安全要求确认 | `battery_full_V`、`battery_empty_V`、`battery_cutoff_V`、`reserve_soc` |
| 最大持续/峰值电流、功率和热限制 | 整包、电调和线束共同限制，记录持续时间 | `max_power_W`；电流和温度限制当前无字段 |
| 端电压、总电流、各单体电压和温度 | 所有推进和飞行试验同步记录 | 用于验证 OCV、内阻、SOC 和功率平衡 |

当前 24 Ah 单芯容量有报告依据，但 7S1P、5 mOhm/芯和分段 OCV 仍是待确认 proxy。`plane.config` 中 5 Ah/25.2 V/0.08 ohm 与 `x8phys.config` 不一致，正式标定时必须消除双重来源。

### 4.8 附属功耗、效率和热状态

| 必采数据 | 工况覆盖 | 配置字段 |
|---|---|---|
| 飞控、传感器、通信、载荷和散热设备功耗 | 上电、待机、解锁、任务、通信/载荷开关组合 | `aux_power_W`；若变化明显需改为模式相关模型 |
| 电机/电调输入输出功率和温度 | 多转速、扭矩、电压和环境温度 | `motor_electrical_efficiency`、`esc_efficiency`；当前为常数 |
| 电机、电调、电池和环境温度时间序列 | 长时稳态、峰值负载和冷却恢复 | 当前无热状态或温度降额字段 |

### 4.9 Plane 端到端响应与联合功率面

每个样本需同步保存 `v_ref`、`eta_ref`、实际地速/空速、风、轨迹、姿态/角速度、PWM、RPM、推力或载荷、端电压/电流、功率、SOC、约束标志和时间戳。

| 必采数据/试验 | 工况覆盖 | `models/plane/+plane/config.m` 字段 |
|---|---|---|
| `v_ref` 阶跃到实际切向地速 | 多初值、升降速、载荷、风和电量 | `speed_tau_s`、`speed_rate_mps2`、`speed_bounds_mps` |
| `eta_ref` 阶跃到实际转速比 | 多初值、总推力和饱和边界 | `eta_tau_s`、`eta_rate_s`、`eta_bounds` |
| 悬停基准功率 | 多电量、载荷和环境，稳态窗 | `hover_power_W` |
| 空速-功率切片 | 全任务空速范围，保持其他量并记录实际值 | `speed_power_gain_W_per_mps2`、`drag_power_gain_W_per_mps2` |
| 转速比-功率切片 | 多总推力、空速和 `eta` 网格 | `eta_power_gain_W` |
| 联合 `P(v_air, eta, turn, battery)` | 直线/圆周、多个半径、风、SOC 和载荷 | 现有四个标量功率字段不足时需升级响应面 |
| 电池和附属功耗 | 与 4.7/4.8 使用同一权威参数 | `battery_*`、`battery_efficiency`、`aux_power_W`、`max_power_W` |

Plane 的 `circle_radius_m`、`altitude_m`、`altitude_ref_m` 和 `sample_time_s` 是场景/数值设置，不从整机功率试验拟合。完成统一接入后，应优先让 Plane 复用 X8PHYS 的物理校准参数，而不是继续维护另一套电池和质量数值。

### 4.10 测量链、风和时间退化

| 必采数据 | 工况覆盖 | 当前配置位置 |
|---|---|---|
| 电压、电流、功率传感器真值对照 | 零点、全量程、不同温度和动态负载 | X8PHYS/Plane 当前无传感器增益、偏置和延迟字段 |
| RPM/PWM 日志与台架仪器对照 | 8 通道、不同转速及丢脉冲场景 | 当前无测量误差字段；`motor_rpm` 仅为对象输出 |
| 空速、地速、姿态和角速度对照 | 静态、直线、转弯、振动和遮挡场景 | 当前无统一 MeasurementAdapter 配置 |
| 风真值/参考与风测量 | 多方向/风速、阵风、延迟、缺测和数据年龄 | 应进入后续 Environment / MeasurementAdapter，不进入物理真值参数 |
| 多设备时间偏移和抖动 | 启停、长时漂移和重连 | 当前无统一时间退化配置 |

这些数据用于建立 `P_meas` 和状态测量链，不得改变 Plane 使用的 `WindTruth`，也不得把真值直接送入控制器。配置入口需在 M4 MeasurementAdapter 实现时新增并登记接口字典。

### 4.11 安全、任务和诊断门槛

以下数值需要由器件额定值、飞控要求和任务安全分析确认，不应通过“让验收通过”反推：

- X8PHYS：`max_power_W`、`max_attitude_rad`、`max_yaw_rate_radps`、`speed_tolerance_mps`、`reserve_soc`、`battery_cutoff_V`、PWM/RPM 边界。
- Plane：`speed_bounds_mps`、`eta_bounds`、`speed_rate_mps2`、`eta_rate_s`、`altitude_tol_m`、`radial_tol_m`、`attitude_tol_rad`、`yaw_rate_tol_radps`、`max_power_W`。

每个门槛必须记录来源类别：制造商绝对额定、连续运行额定、项目保守限制或试验识别边界。只有制造商值仍不足以证明整机安全；需要在受控试验中验证保护触发、恢复和裕量。

### 4.12 不通过实测辨识的配置字段

为保证配置字段没有遗漏，下列字段仍需管理，但不是从推进/飞行数据拟合：

| 字段 | 位置 | 如何确定 |
|---|---|---|
| `schema_version` | X8PHYS、Plane 两个 `config.m` | 接口 schema 变化时按版本治理更新 |
| `parameter_source` | `x8phys.config` | 发布校准参数集时改为可追溯 calibration ID；当前保持 `proxy_static_test_fit_2026-07-04` |
| `plane_model_id`、`power_model_id` | `plane.config` | 模型结构或参数集变化时更新版本 ID，不由传感器拟合 |
| `gravity_mps2` | X8PHYS、Plane 两个 `config.m` | 默认使用标准重力；需要高精度时按试验地点纬度/海拔计算，不能作为自由拟合量 |
| `min_soc`、`max_soc` | `x8phys.config` | SOC 状态的数学边界；实际可用窗口由 OCV、截止电压和 `reserve_soc` 定义 |
| `sample_time_s` | `plane.config` | 由统一仿真/控制时基和传感器采样率设计确定，并通过离散化收敛测试验证 |
| `circle_radius_m`、`altitude_m`、`altitude_ref_m` | `plane.config` | 场景/任务配置；实际轨迹数据用于验证跟踪，不将它们拟合成机体参数 |

`plane_proxy_p0p4_v2` 和 `joint_proxy_v1` 是当前两个 ID 的取值，不是独立字段或测量量。

## 5. 当前没有配置字段、必须先扩展模型的项目

1. 三轴重心和每个旋翼的完整三维安装位置。
2. 上下桨间距及同轴推力、扭矩、功率干扰图。
3. 动态 `Ct/Cq/Cp(J)`、侧向来流和动态入流查表。
4. 个体电机/电调/桨差异，以及上升/下降不对称、纯延迟和滞回。
5. 迎角/侧滑相关的升力、侧力和气动力矩。
6. SOC/温度/倍率相关的 OCV、内阻、容量、库仑效率和电池热模型。
7. 电机、电调、电池温度状态与热降额。
8. 模式相关附属功耗和载荷功耗。
9. 传感器增益、偏置、噪声、延迟、时间抖动、数据年龄和缺测模型。
10. 参数协方差、批次差异和隐藏参数集版本。

这些项目在接口和验收设计完成前保持“未实现”，不能把数据写入相近但语义不同的字段。

## 6. 清洗、辨识和验证交付物

每一类校准至少交付：

1. 原始数据登记和 SHA-256；受限源文件只登记哈希，不提交内容。
2. 字段字典、单位转换、坐标/符号和时间对齐说明。
3. 可重复运行的清洗脚本与异常点报告，禁止手工覆盖原值。
4. 参数辨识脚本、目标函数、约束、初值和收敛诊断。
5. 参数值、单位、置信区间/不确定度、适用范围和外推行为。
6. 按完整试验 run/硬件批次划分的 calibration 与 holdout 集；不得用相邻样本随机泄漏。
7. 留出验证的时域误差、功率/能量误差、最坏场景和重复性。
8. 新参数集 ID、代码提交、配置差异和回退参数集。
9. MATLAB 单元/契约测试及统一 Harness 配对回归。
10. 结论等级和不能外推的范围；未通过留出验证时仍标记 `proxy/estimated`。

## 7. 推荐实施顺序

1. 确认整机硬件清单、质量/重心/惯量、旋翼几何和真实电池 S/P。
2. 完成单桨静态推进复核，并新增同轴 `eta` 网格试验。
3. 完成电机动态、电池脉冲/容量和附属功耗试验。
4. 取得非零来流 `Ct/Cp(J)` 与机身气动数据，必要时用 CFD/BEMT 先验辅助但保留实测留出集。
5. 在统一 Plane 中辨识速度/`eta` 动态和联合功率面，消除 Plane/X8PHYS 双重参数来源。
6. 建立 MeasurementAdapter，再用独立台架/飞行 run 做端到端留出验证。
7. 通过校准与验证后才把 `parameter_source` 从 `proxy_*` 提升为版本化 calibration ID；随后复跑 M0--M3 和统一 Harness。
