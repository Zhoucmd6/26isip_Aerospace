## 关键决策与理由

- 两个新模块以功能名入库：`wind_semantics_correction`（语义参考实现）、
  `wind_inference_search`（第二轮能力模块）；模块 README 标注本地编号对应关系。
- 第一轮"谷底测量不含风信息"的探针瓶颈，在本模块的答复是**换信息来源而非调参数**：
  激励从速度 dither 改为转圈航向扫描（免费），调度从"追着最优跑"改为"估风+闭式解算"。
  这是 1.x 线恒定风下因果策略不敌开环（0.94 vs oracle 0.9988）到 2.1 逼近上限（0.9945）
  的全部原因——信息结构变了，不是算法变聪明了。
- est（EKF+dither）保留为对照：无风时 9.4% 超额，探针成本如实可见。
- 2.2（曲线未知 + 强化学习，参考 speed_rl_pytorch 但须严格甄别）**等用户确认后再启动**。
