# 项目整理总结——共轴八旋翼在线速度寻优算法线（截至 2026-09-11）

作者：王健祺（算法线）；ZCode 协助整理。本文是算法线的阶段性总结与材料索引，
供项目汇报与后续接续使用；项目整体状态以 [`DEVELOPMENT_STATUS.md`](DEVELOPMENT_STATUS.md) 为权威。

## 一、一句话总结

面向共轴八旋翼圆周巡航场景，在"曲线未知、风未知、只读带噪功率"的因果约束下，
构建了从扫频标定、纯奖励强化学习到预训练拆分的四条在线速度寻优管线，
并完成了本地代理 → 平台 P2 物理链的数据源对等迁移与验收——
**最终 9000s 平台验收全部学习算法优于开环基线（最好臂 −1.21%，即优于恒速最优参考）**。

## 二、算法线演进（任务 1.x → 3.7）

| 阶段 | 模块（本地/仓库） | 内容与结论 |
|---|---|---|
| 1.1–1.7 搜索与风场 | speed_esc 系列 | 任务1 曲线已知：网格/多起点/牛顿等搜索器横评；后续按 2026-09-07 精简口径删除 task1 遗留直接搜索器 |
| 1.8 真实约束重评估 | realistic_constraints_search | **核心负结果**：R=50–150m 空速物理+风摆 ±3–4 m/s 下，"谷底测量"不含风信息，因果策略不敌开环（5.6% vs oracle 0.2–0.4%）——激励必须改为航向扫描 |
| 1.9–1.11 曲线族/风场库/风语义 | curve_case_calibration / wind_model_library / wind_semantics_correction | 曲线族（谷底 95/90/85%）、七种风场、空速=地速−风语义统一 |
| 2.1 风速推断寻优 | wind_inference_search | 突破探针瓶颈：转圈航向扫描估 2 个风参数 + 闭式调度 **v\*=q+√(q²+û\*²−\|ŵ\|²)**；恒风零探针 MOE 0.9945（known 上限 0.9988） |
| 3.1 曲线未知 | curve_unknown_search（sweepcal） | 全速域双向扫频 + 曲线 f 与风 w 联合辨识（四阶多项式归一化基），20 步重拟合+探针信赖域 |
| 3.2 纯奖励 RL | reward_only_rl（purerl） | 不标定曲线，只从功率奖励学习：对偶交替探索+分桶基线+邻域核 REINFORCE |
| 3.3 标定+风推断混合 | curve_calib_windinfer（hybrid） | 冻结曲线只跟踪风；结论：恒风可用、变风必须继续重拟合/RL |
| 3.4 四算法统一横比 | unified_four_algos | sweepcal / hybrid / rl / purerl(off/on) 统一 MOE 口径横比；修截断拟合边缘假谷（样本支撑谷底选择+标定块支撑+信赖域） |
| 3.5 预训练拆分 | purerl_pretrain_split | purerl_on（在线微调）/ purerl_off（冻结部署）：试飞时段预训练不计评测预算；本地 MOE purerl 0.958（scratch）→ 0.985（off） |
| 3.6 平台对接 | platform_link | 数据源从本地代理换成平台 P2 物理链（冻结链：俯仰内核/台架功率合成/H3 诱导/H9 上限/电池链）；就位委托制+秒预算；9000s 十倍窗验收全臂优于开环 |
| 3.7 已标定好变体 | platform_link_37 | sweepcal/hybrid/rl 增加已标定好变体（标定移独立试飞架次，MOE 只计标定后）；本地瓦数显示口径修复 |

## 三、3.6 平台对等：数据源一致性修复清单（N1–N10）

| # | 修复 | 要点 |
|---|---|---|
| N1 | q() 功率归一化 | 平台原始瓦数→悬停=1 口径，拟合不再出界 |
| N2 | 就位委托制 | q() 内部循环推进直至 \|v_ground−v_ref\|≤0.1，秒预算照计 |
| N3 | RL 更新门放行 | 就位委托下测量必已就位，瞬态门按标志放行 |
| N4 | 预训练数据源 | 平台后端预训练改在平台 plant 上（消除本地谷底 6.3 vs 平台 5.15 偏移）+ 缓存模型 |
| N5 | 拟合抗退化 | 帧坍缩判据（P 只是空速的函数）+ 谷底内点约束；B=3.5 û* 从 11.25 回到 3.96 |
| N6 | 扫频扩展+探针调优 | 平台 [2,13.5]×100（本地 [3,12]×150 不变，分支覆写） |
| N7/N8 | 显示与部署 | 平台真实瓦数显示；仓库根多候选探测 |
| **N9** | **ψ̂ 冻结根因** | **平台 count() 浮点漂移使 sUsed=0.999…<1，`for j=1:sUsed` 零迭代 → 航向死推自锁**（"百余步后速度不变"的直接根源）；7 文件 10 处改直乘 |
| N10 | 塌缩守卫统一 | disc<0 兜底统一"保持上一可行指令+0.8û\*托底"，杜绝近悬停塌缩 |

重要教训：修复前 purerl_off 的 0.54% 是 ψ̂ 冻结自锁的假象（恒飞 bin10≈3.3 恰近平均最优）；
解冻后暴露旧缓存分箱垃圾（14.38%），按修复后语义重生成缓存（muB 呈正确方位角轮廓）后
反而成为最优臂——**评估语义改变时，所有配套数据（含预训练产物）必须同语义重生成**。

## 七、遗留与建议

1. 真航向反馈（M4 路线图既有条款）：算法 ψ̂ 死推与平台 v_ground 推进的瞬态积分差，彻底解决需反馈；
2. 多种子统计：现有验收为单种子（seed=11），正式统计口径建议 ≥3 种子；
3. B=3.5 强风下 purerl 对等性、sweepcal 长窗 windErr 漂移（2.8→4.6）建议 M4 一并处理；
4. MATLAB R2022b 运行时堆崩溃（0xc0000374/0xc0000005）为环境级 OPEN LIMITATION：长批串行跑、重跑即恢复；
5. 演示建议任务窗 ≥9000s（600s 窗标定学费占比过高，不代表收敛后水平；或用 3.7 已标定好变体）。
